# TG任务助手前台面板

## 简介

`TG任务助手前台面板` 是任务助手的前端界面脚本，用于读取 `TG任务状态后台扫描器` 保存的共享结果，并在 TG / Educoder 页面中展示任务信息。

## 主要功能

- 在页面右侧提供任务助手入口与抽屉面板
- 汇总展示课程中的考试、小测试、图文作业等任务
- 根据任务状态和截止时间整理任务信息
- 支持课程与任务筛选
- 支持课程置顶、任务忽略、折叠等常用管理操作
- 支持手动刷新，并与后台扫描器联动更新数据
- 保存面板状态、筛选条件、快捷键等本地设置
- 对临近截止的任务提供醒目标识

## 使用要求

本脚本需要与 `TG任务状态后台扫描器` 配合使用。后台扫描器负责获取任务数据，本脚本负责读取并展示这些数据。

支持页面包括：

- TG 外网
- TG 校园内网
- Educoder / 头歌

## 说明

脚本只负责前端展示与交互，任务数据由后台扫描器获取并写入共享存储。建议同时安装并启用两个脚本。
