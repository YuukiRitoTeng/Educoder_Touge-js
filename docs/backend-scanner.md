# TG任务状态后台扫描器

## 简介

`TG任务状态后台扫描器` 是任务助手的数据采集脚本，负责在后台扫描 TG / Educoder 中的课程与任务状态，并把结果保存到共享存储，供 `TG任务助手前台面板` 读取展示。

## 主要功能

- 后台获取正在进行的课程
- 扫描考试和小测试状态
- 扫描图文作业等课程任务
- 汇总 TG 与 Educoder 的任务结果
- 将课程和任务整理为统一的数据结构
- 保存扫描结果、运行状态和错误信息到共享存储
- 响应前台面板发出的刷新请求
- 支持 TG 外网、TG 校园内网和 Educoder / 头歌

## 使用要求

- 浏览器需要保持对应平台的有效登录状态
- 脚本依赖当前浏览器的登录 Cookie 获取课程与任务信息
- 建议与 `TG任务助手前台面板` 一起安装使用

## 工作方式

后台扫描器负责获取和整理数据，不提供主要可视化界面；前台面板通过相同的共享存储读取扫描结果并展示任务信息。
